# 💬 Türkçe Restoran Yorumları Duygu Analizi & Sınıflandırma (NLP)

Bu proje; Türkçe kullanıcı yorumları üzerinde Doğal Dil İşleme (NLP) ve Derin Öğrenme teknikleri kullanılarak duygu analizi (Sentiment Analysis) gerçekleştiren uçtan uca bir yapay zekâ uygulamasıdır. Projede metin sınıflandırma amacıyla **BERT (Transformer)**, **LSTM** ve **GRU** mimarileri eğitilmiş, karşılaştırılmış ve **Streamlit** web arayüzü ile kullanıcı deneyimine sunulmuştur.

---

## 📌 Proje Özellikleri
- **Çoklu Model Desteği:** BERT, LSTM ve GRU mimarileriyle tahmin ve performans kıyaslaması.
- **Türkçe Metin Ön İşleme:** Metin temizleme, tokenizasyon, dolgu (padding) ve vektörleştirme adımları.
- **Canlı Web Arayüzü:** Kullanıcının yazdığı restoran değerlendirmesini anlık olarak analiz eden etkileşimli Streamlit paneli.

---

## 🛠️ Kullanılan Teknolojiler & Kütüphaneler
- **Programlama Dili:** Python 3.x
- **Derin Öğrenme (Deep Learning):** TensorFlow, Keras (LSTM, GRU), Hugging Face Transformers (BERT)
- **Doğal Dil İşleme (NLP):** Tokenizer, Sequence Padding
- **Arayüz (Frontend):** Streamlit
- **Veri Manipülasyonu:** NumPy, Pandas
